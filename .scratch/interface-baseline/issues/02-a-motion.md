# A：核实停止、踏步与 A 失效时的原装断电能力

## Question

与 C/D 核实统一运动、停止移动、停止行为、原地踏步接口及底层实际效果。A 必须检测 C 有效运动指令超时并自行停止。A 自身失效目标为层级 3 强制断电，快速验证版不增设额外冗余；不能假设失效进程仍能执行断电。

产出：原装接口及触发路径证据、C/A 指令契约、真机验证方案与已验证/未验证能力清单。普通停止不能充作强制断电；若原装能力无法满足，报告缺口交团队按版本取舍处理，不能自行改硬件。具体数值依据实测。
