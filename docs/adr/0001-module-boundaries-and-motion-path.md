# D 统一用户入口，C 统一运动保护，A 执行，B 管理地图

状态：accepted；决议日期：2026-11-02。

团队需要复用现有软件并允许模块并行细化，因此按业务责任划分 A/B/C/D，每个模块以主要集成包组织上游软件与缺口代码，而不把包、节点、进程与人员绑定为一对一。D 统一用户交流和流程协调，运动指令始终经 D→C→A，B 拥有运动估计及地图能力；D 调用能力而不重复实现业务逻辑，C 的障碍保护不依赖全局定位正常。

这一选择避免复用的遥控入口绕过保护，也允许成员互助而不改变接口责任；改变通路会影响多个模块，须共同确认。具体行为以[阶段决议 §5、§7.10–§7.17](../survey/2026-11-01-interface-baseline-decisions.md)为准，尚不代表实现完成。
