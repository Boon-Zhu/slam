# 快速验证优先闭环取数，并显式保留故障覆盖缺口

状态：accepted；决议日期：2026-11-02；适用范围：快速验证版。

团队先需要可运行闭环和真实数据，因此快速验证版以一次遥控、采集、建图与保存为完成条件，不以独立定位、长时间稳定性或完整边界验证为门槛；交付版补齐约定功能与完整验证。设备及数据错误由 A 报告、B/C 根据报告响应，快速验证版不增加完整独立下游校验或额外冗余。

雷达故障允许用户确认后重新持续操作运动，并明确显示避障未生效；这与一律停车相比接受了人工观察下的感知降级。仅 A→D 错误上报通道失联且其他必要链路正常时不触发运动降级或停车，各模块保留日志供试运行后交叉核对；该例外不能扩大到指令失联或 A 自身失效。

运动指令链路超时仍须停止行为，A 自身失效仍以强制断电为目标，但原装断电接口和失效时可用性尚待核实，不能将目标记为已实现能力。日志是事后证据，不替代实时故障响应；快速验证结果不能充作交付验收。完整边界见[阶段决议 §7.7–§7.9、§7.14、§7.26、§7.29](../architecture/interface-baseline-decisions.md)。
