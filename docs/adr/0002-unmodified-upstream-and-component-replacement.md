# 保持上游原样，缺口以最小独立组件自研替换

状态：accepted；决议日期：2026-11-02。

团队希望尽快复用成熟能力，同时降低 agent 大量参与实现时的补丁维护和检查负担，因此只采用自研代码与未修改上游，优先通过自有配置和公开接口组合；确需修改实现时，替换最小独立节点或组件，所依赖的上游库保持原样，而不维护上游修改分支。

代价是自研替代组件承担测试与接口兼容责任，原样复用也不免除版本、构建及集成验证；若替换深入驱动协议或算法核心，先评估换组件、换原版版本或延期非必需功能，不自动重写核心。复制上游后改名修改不构成独立自研。决议与工作量评估入口见[阶段决议 §7.19–§7.20](../survey/2026-11-01-interface-baseline-decisions.md)。
